# Below the Line

A simple browser-based game that simulates the challenges of living with limited financial resources.

## How to play
- Manage income, bills, essentials, savings, and debt.
- Use actions to borrow money, cut spending, apply for support, take a gig, or pay debt.
- Advance the month to face random events and track progress.
- Survive for 12 months to win.

## Files
- `index.html` — game UI and layout
- `styles.css` — styling for the dashboard and log
- `game.js` — main simulation logic and state management

## Run
Open `index.html` in a browser to start the game.
